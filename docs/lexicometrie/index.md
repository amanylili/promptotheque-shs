# 📊 Lexicométrie

Prompts pour l'analyse statistique des données textuelles. Tous imposent un **calcul réel**, par code exécuté ou par script fourni. L'assistant aide ensuite à **interpréter** les résultats.

| Prompt | Pour… | Niveau |
|---|---|---|
| [Comptage de fréquences](comptage-frequences.md) | Dictionnaire de fréquences, hapax, richesse lexicale, loi de Zipf | Débutant |
| [Calcul des spécificités](calcul-specificites.md) | Mots sur- et sous-employés dans une partie du corpus (modèle hypergéométrique de Lafon) | Intermédiaire |
| [AFC sur tableau lexical](afc-tableau-lexical.md) | Analyse factorielle des correspondances formes × parties | Avancé |
| [Cooccurrences](cooccurrences.md) | Attractions lexicales autour d'un pôle | Intermédiaire |
| [Classification (méthode Reinert)](classification-reinert.md) | Préparer, paramétrer et interpréter une classification descendante hiérarchique | Intermédiaire |

!!! warning "Rappel"
    Un résultat lexicométrique n'est pas une interprétation. Revenez toujours au texte, par les concordances, avant de conclure.
